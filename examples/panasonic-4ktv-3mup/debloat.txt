# Panasonic 4KTV-3MUP (ro.product.manufacturer MOKA, device R4_GTV, Realtek RTD2851), Google TV build of
# Android TV 14 (API 34), build UKR1.260308, security patch 2026-04. Malaysia unit.
# Not the same platform as examples/panasonic-4ktv-jup (MediaTek): only the Google packages carry over.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/panasonic-4ktv-3mup/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/panasonic-4ktv-3mup/debloat.txt com.google.android.apps.tv.launcherx
# Windows: tools\restore.ps1 -TvHost <tv ip> examples\panasonic-4ktv-3mup\debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx. HOME claimants: launcherx, setupwraith
# (.RecoveryActivity) and com.android.tv.settings FallbackHome. setupwraith takes Home once launcherx is
# disabled: the first install attempt rolled itself back until setupwraith was disabled (listed below).
#
# WARNING, seen 2026-10-25 on this TV: two days after the install, an update re-enabled setupwraith (and
# play.games, feedback, partnersetup, calendar sync). Its .RecoveryActivity took Home again, and every press
# of Home crashed the system and rebooted the TV to the Panasonic logo; HDMI, the TV tuner and the YouTube /
# Netflix buttons kept working. The TV also came back on a new IP after the reboots, which hid that network
# debugging was still on. Fixed over ADB at the new address: `pm enable --user 0
# com.google.android.apps.tv.launcherx`, then `cmd package set-home-activity --user 0
# com.google.android.apps.tv.launcherx/.home.HomeActivity`.
#
# So install Glass TV here with the stock launcher kept as the system's Home:
#   launcher\build-and-install.ps1 -TvHost <tv ip> -KeepStockHome      (macOS/Linux: KEEP_STOCK_HOME=1)
# HomeKeyService then brings Glass TV up over the Google TV home screen after boot and on every Home press
# (this TV handles Home before accessibility services, so it watches for the stock screen instead); press
# Home again within 2.5 s to stay on Google TV. Tested 2026-10-25: Home press and a reboot. Leave
# setupwraith and launcherx enabled: the setupwraith line below is commented out for that reason.
#
# Tested 2026-10-23 on one TV, in three batches; after each the owner checked Home, the remote, Wi-Fi and
# an HDMI input. A deliberately short list: under a day of use when submitted.
#
# DO NOT DISABLE (load-bearing on this firmware):

# com.realtek.tv.passthrough                                         # HDMI inputs

# USB media player, OTA (com.apps.ota, com.realsil.ota), all streaming apps.
